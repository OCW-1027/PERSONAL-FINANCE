# PERSONAL-FINANCE — 個人事業 財務管理システム / 개인사업 재무관리 시스템

複式簿記ベースの個人事業主向け財務管理システム。**한국어 / 日本語 切替対応**。
青色申告決算書・収支内訳書の両方に対応します。

## 特徴 / 특징
- 複式簿記(青色65万控除の要件を満たす) — 복식부기
- **한국어 UI + 일본어 계정과목 병기** (申告書にそのまま転記可能)
- 家事按分の自動計算 — 가사안분 자동
- 開業費の任意償却シミュレーション — 개업비 임의상각
- 損益計算書 / 貸借対照表(貸借自動一致) — PL/BS
- 事業所得・不動産所得の損益通算 — 손익통산
- 税額の即時試算(所得税・住民税・個人事業税・国保)
- 経費台帳(CSV/Excel)の一括取込 — 경비대장 일괄 취입
- 手当 判定所得トラッカー — 수당 판정소득 트래커

## 使い方 / 사용법
1. `index.html` をブラウザで開く
2. 初回セットアップで言語・氏名・開業日を設定
3. 設定タブで申告種別・所得控除を入力
4. 伝票処理タブで入力、または経費台帳を貼り付けて一括取込

## 配布時 / 배포 시
`data.js` を `data.blank.js` に差し替えると初期データなしで起動します。

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面 |
| lang.js | **한국어/日本語 문구 + 계정과목 대역** |
| data.js | 勘定科目マスタ・税制パラメータ・初期データ |
| app.js | 計算エンジン・画面描画 |
| style.css | スタイル |

## 注意
税制パラメータは `data.js` の `TAX` に集約。改正時はここだけ更新してください。
本システムは記帳補助であり、税務申告は税理士・税務署にご確認ください。
