# PFS — Personal Finance System
### 個人事業 財務管理システム / 개인사업 재무관리 시스템

複式簿記ベースの個人事業主向け財務管理システム。**한국어 / 日本語 切替対応**。
青色申告決算書・収支内訳書の両方に対応します。

## 特徴 / 특징
- 複式簿記(青色65万控除の要件を満たす) — 복식부기
- **한국어 UI + 일본어 계정과목 병기** (申告書にそのまま転記可能)
- 家事按分の自動計算 — 가사안분 자동
- 開業費の任意償却シミュレーション — 개업비 임의상각
- 損益計算書 / 貸借対照表(貸借自動一致) — PL/BS
- 事業所得・不動産所得の損益通算 — 손익통산
- 税額の即時試算(所得税・住民税・個人事業税・国保)
- 経費台帳(CSV/Excel)の一括取込 — 경비대장 일괄 취입
- 手当 判定所得トラッカー — 수당 판정소득 트래커

## 使い方 / 사용법
1. `index.html` をブラウザで開く
2. 初回セットアップで言語・氏名・開業日を設定
3. 設定タブで申告種別・所得控除を入力
4. 伝票処理タブで入力、または経費台帳を貼り付けて一括取込

## 配布時 / 배포 시
`data.js` を `data.blank.js` に差し替えると初期データなしで起動します。

## PWA — アプリとしてインストール / 앱 설치
- **PC(Chrome/Edge)**: アドレスバー右の ⊕ か、左メニュー下の「Install」ボタン
- **Android**: メニュー →「ホーム画面に追加」
- **iPhone(Safari)**: 共有 →「ホーム画面に追加」

インストール後は **オフラインでも動作**します(電車・機内でも入力可)。

## データ保護 / 데이터 보호
| 仕組み | 内容 |
|---|---|
| 自動スナップショット | 保存5回ごとにブラウザ内(IndexedDB)へ世代保存。直近20世代 |
| 自動復旧 | キャッシュ削除等でデータが消えた際、起動時に復旧を提案 |
| バックアップ督促 | 7日以上未バックアップでダッシュボードに警告 |
| 手動バックアップ | 設定→バックアップ出力(JSONファイル) |

⚠️ **ブラウザデータを完全削除するとスナップショットも消えます。月1回はバックアップファイルのダウンロードを推奨します。**

## データ更新 / 데이터 갱신
`data.js` を新しくしたら、先頭の **`DATA_VER`** を新しい日付(yyyymmdd)に更新してください。
アプリ起動時に差分の伝票だけを検出し、「追加しますか？」と確認します。
既存データは保持され、重複は自動的に除外されます。

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面 |
| lang.js | **한국어/日本語 문구 + 계정과목 대역** |
| data.js | 勘定科目マスタ・税制パラメータ・初期データ |
| app.js | 計算エンジン・画面描画 |
| safe.js | データ保護(スナップショット・復旧) |
| style.css | スタイル |
| manifest.json | PWA 定義 |
| service-worker.js | オフライン対応 |
| icon-192.png / icon-512.png | アプリアイコン |

## 注意
税制パラメータは `data.js` の `TAX` に集約。改正時はここだけ更新してください。
本システムは記帳補助であり、税務申告は税理士・税務署にご確認ください。
