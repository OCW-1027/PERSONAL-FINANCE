# PERSONAL-FINANCE — 個人事業主 財務管理システム

複式簿記ベースの個人事業主向け財務管理システム。青色申告決算書・収支内訳書の両方に対応。

## 特徴
- 複式簿記(青色65万控除の要件を満たす)
- 家事按分の自動計算(在宅勤務の賃料・水道光熱費)
- 開業費の任意償却シミュレーション
- 損益計算書 / 貸借対照表(貸借自動一致)
- 事業所得・不動産所得の損益通算
- 税額(所得税・住民税・個人事業税・国保)の即時試算
- 経費台帳(CSV/Excel)の一括取込
- 手当 判定所得トラッカー(所得制限の監視)

## 使い方
1. `index.html` をブラウザで開く
2. 初回セットアップ(氏名・開業日・年度)
3. 設定タブで申告種別・所得控除を入力
4. 伝票処理タブで入力、または経費台帳を貼り付けて一括取込

## 配布時
`data.js` を `data.blank.js` に差し替えると初期データなしで起動します。

## ファイル
- index.html — 画面
- app.js — 計算エンジン・画面描画
- data.js — 勘定科目マスタ・税制パラメータ・初期データ
- style.css — スタイル

## 注意
税制パラメータは data.js の `TAX` に集約。改正時はここだけ更新してください。
本システムは記帳補助であり、税務申告は税理士・税務署にご確認ください。
